Export

When you click the button below HyScribe will create an XML file for you to save to your computer.

This format, which is called eXtended RSS or WXR, will contain your posts, pages, comments, custom fields, categories, and tags.

Once you’ve saved the download file, you can use the Import function in another HyScribe installation to import the content from this site.
